
Lab: Scanning for SMB Vulnerabilities
Course: Cisco Ethical Hacker

--------------------------------------------------
Step 1: Root Access
--------------------------------------------------
Command:
sudo su

Purpose:
To switch to the root user in order to execute privileged network scanning and enumeration commands.

Observations:
The terminal prompt changed from a normal user to root, indicating elevated privileges.

Results:
Root access was successfully obtained.

--------------------------------------------------
Step 2: Identify Live Hosts
--------------------------------------------------
Command:
nmap -sN 10.0.2.15/24

Purpose:
To perform a TCP Null scan on the target network to identify live hosts and potential open or filtered ports.

Observations:
The scan returned responses from multiple hosts within the subnet.

Results:
Active hosts on the 10.0.2.15/24 network were identified.

Screenshot Reference:
cmd2_nmap_null_scan.png
